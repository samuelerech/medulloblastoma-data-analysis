# Medulloblastoma Clinical and Molecular Exploratory Data Analysis (EDA) 🧬🧠

This repository contains an Exploratory Data Analysis (EDA) pipeline focused on the clinical and molecular profiling of Medulloblastoma samples. Medulloblastoma is the most common malignant brain tumor in children, originating in the cerebellum. Modern neuro-oncology classifies this disease into four distinct molecular subgroups: **WNT**, **SHH**, **Group 3**, and **Group 4**, each characterized by unique clinical behaviors, age profiles, and genetic alterations.

The analysis is based on the landmark dataset published by the **DKFZ (German Cancer Research Center)** in *Nature* (2017), showcasing clinical annotations from 491 patients.

## 🧬 Biological Background & Objectives

The goal of this project is to address four fundamental biological and technical questions through data science workflows:
1. **Age at Diagnosis vs. Molecular Subgroups:** Do specific genetic cohorts target molecular subsets of patients (e.g., infants vs. adolescents/adults)?
2. **Tumor Mutational Burden (TMB) and Genomic Complexity:** Does chromosomal instability (measured by estimated ploidy) correlate with higher mutation rates?
3. **Sex Distribution:** Is there an underlying sex bias across different molecular variants?
4. **Sequencing Technology Quality Control:** How does sequence coverage (fold-coverage) differ between Whole Genome Sequencing (WGS) and Whole Exome Sequencing (WES) across patient cohorts?

## 📊 Dataset Availability & Download

The molecular and clinical annotations dataset used in this analysis is publicly available on cBioPortal:

* **Direct Study Link:** [cBioPortal Medulloblastoma (DKFZ, Nature 2017)](https://cbioportal.org)
* **Instructions:** Go to the link above, click on the **"Clinical Data"** tab in the top menu, and click the download button to get the TSV file. Place the file inside the root of your project directory and rename it to `mbl_dkfz_2017_clinical_data.tsv`.

## 🛠️ Prerequisites & Installation

To run this pipeline locally, you need Python 3.8+ installed.

1. Clone the repository:
```bash
git clone https://github.com
cd medulloblastoma-data-analysis
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the Jupyter Notebook:
```bash
jupyter notebook medulloblastoma_eda.ipynb
```
*Note for Google Colab users: If you upload this notebook to Colab, make sure to upload the `mbl_dkfz_2017_clinical_data.tsv` file to your Colab environment sidebar before running the cells.*

## 📉 Key Insights & Results

The complete exploratory analysis is summarized in a professional 4-panel dashboard generated by the code:

### 1. Age Distribution by Subgroup and Sex
* **SHH** group displays a broad, bimodal distribution, presenting significantly in infants (<3 years) and adult populations.
* **Group 3** and **Group 4** tumors are tightly restricted to pediatric ranges (median age ~6–9 years).

<img width="636" height="427" alt="image" src="https://github.com/user-attachments/assets/11808e8b-aeb7-43a7-b49b-575060624a40" />

### 2. Mutational Landscape and Ploidy
* **SHH** and **WNT** tumors exhibit higher baseline mutation counts compared to non-WNT/non-SHH variants.
* Tetraploid (4.0) or aneuploid variants do not strictly scale with a linear increase in mutation counts, suggesting that structural copy-number changes can act as distinct oncogenic drivers independent of point mutation rates.

<img width="632" height="425" alt="image" src="https://github.com/user-attachments/assets/18c77d29-6bfd-4566-99f6-55616ad608f3" />

### 3. Sex Disparity
* There is a striking predominance of **Male** patients in **Group 3** and **Group 4** subtypes, highlighting a biological gender bias frequently reported in embryonal neuro-oncology.

<img width="627" height="432" alt="image" src="https://github.com/user-attachments/assets/ebc2214c-5bc1-46f3-b41e-62e0294f7e99" />

### 4. Sequencing Platform Benchmarking
* The coverage analysis validates technical assay performances: Whole Genome Sequencing (WGS) targets a tight, high-quality window around 30x–50x coverage, whereas Whole Exome Sequencing (WES) distributes widely into deep depths (70x–190x) specifically targeting coding regions.

## 💻 Code & Implementation Details

The pipeline follows production-grade Open Science guidelines:
* Robust type conversion using `pd.to_numeric` with string-coercion to eliminate empty or invalid string cells (`"NA"`).
* Integration of explicit `BIOLOGICAL QUESTION` and `BIOLOGICAL INSIGHT` comments directly into the Python script to bridge data science and cancer biology.
